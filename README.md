# !

A small birthday surprise website in a green "hacker terminal" style.

It asks a couple of questions, pretends to hack the visitor's phone,
then reveals a Happy Birthday screen with a cake, music and falling code.

## Files

| File         | What it is                                  |
|--------------|---------------------------------------------|
| `index.html` | The page, plus the **EDIT HERE** settings   |
| `style.css`  | All the styling                             |
| `script.js`  | All the behaviour                           |
| `_headers`   | Security headers (Netlify / Cloudflare Pages) |

## Change the texts

Open `index.html` and scroll to the **EDIT HERE** block near the bottom.
You can change the questions, the messages, the birthday wish and the phone number there.

## Run it

No build step. Open `index.html` in a browser, or host the folder on
GitHub Pages, Netlify or Cloudflare Pages.
